
# 📋 Simple CRUD Operation

## 📌 About The Project

The Simple CRUD Operation is a web-based application that demonstrates the basic database operations: Create, Read, Update, and Delete.

It allows users to manage records easily through a simple and user-friendly interface.

## ✨ Features

- **Create:** Add new records to the database.
- **Read:** Display and view existing records.
- **Update:** Edit and modify existing records.
- **Delete:** Remove unwanted records.
- User-Friendly Interface
- Database Connectivity
- Form Validation (if implemented)

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling and layout
- **JavaScript** – Interactive functionality
- **PHP** – Backend development
- **MySQL** – Database management

## 🚀 Installation & Setup

1. Clone this repository:

```bash
git clone https://github.com/Mehulluhar24/simple-crud-operation.git
```

2. Move the project folder into the XAMPP `htdocs` directory.

3. Start Apache and MySQL using XAMPP.

4. Open phpMyAdmin and create the required database.

5. Import the database SQL file if provided.

6. Open your browser and visit:

```text
http://localhost/simple-crud-operation/
```
